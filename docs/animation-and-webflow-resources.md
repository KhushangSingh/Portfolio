# Animation and Webflow references

## Lottie and After Effects

- [Lottie Web repository and player API](https://github.com/airbnb/lottie-web)
- [Bodymovin After Effects exporter](https://aescripts.com/bodymovin/)
- [Adobe Exchange listing](https://exchange.adobe.com/creativecloud.details.12557.html)
- [Composition and export settings](https://github.com/airbnb/lottie-web/wiki/Composition-Settings)

Export the composition as JSON with Bodymovin. For a future Lottie asset, the player can load either a JSON file path or in-memory animation data. Use the player API to start it when visible and pause it while offscreen. When unmounting the feature, call `destroy()` on its animation instance. Use the repo instructions for current installation options.
