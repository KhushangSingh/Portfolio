# Portfolio design rules

- Start each page and section with its main heading. Place role, discipline and section labels in supporting copy or metadata when they help the reader.
- Use text labels for interface controls and workflows. Do not use Lucide or generic UI icons. Use authentic brand logos for named tools, platforms and products when the artwork is available. Keep original illustrations and interactive objects as artwork.
- Give each project case study its product’s own colors and visual language. Use authentic product screens for previews and retain the portfolio theme controls around them.
- Avoid thin colored accent borders on individual edges throughout the portfolio. Use neutral outlines, spacing or a filled surface for emphasis.

## Portfolio writing rules

- Never place a comma immediately before “and” or “or”. Rephrase the sentence when needed for clarity.
- Never use em dashes. Rephrase the sentence or split it into shorter sentences.
